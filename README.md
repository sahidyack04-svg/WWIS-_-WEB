# WWIS Trichy Website

Website project for **Wisdom Wealth International School (WWIS), Trichy** — a Cambridge (CIE) curriculum school.

Live reference: https://wwis2026web.vercel.app/index.html

## About WWIS

> "Schools focus on Class but We focus on Individual Child."

WWIS follows the Cambridge (CIE) curriculum with an Individual Learning Plan (ILP) guiding every student through three continuous stages:

- **iPlay** (Pre-KG–Grade 2) — brain development · 24 skills · 3 languages
- **iDiscover** (Grade 3–7) — discovering passion · 24 projects · 8 professional skills
- **iLead** (Grade 8–12) — launching careers · 3 career programs · 5 internships

## Site Structure
